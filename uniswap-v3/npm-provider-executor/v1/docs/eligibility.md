# Eligibility boundary

## True in this slice

- A hermetic host provider evaluates every request in the conservative NPM
  observation plan in Position, Pool, then Token phase order.
- Resolved None/Missing results remain distinct from PossibleReorg, Unknown,
  and provider error; every unstable/error outcome aborts before reduction.
- Exact EIP-1898 hash and explicit block-number fallback scopes are supported.
- Exact-key preflight is mandatory before the certified joint reducer.
- A deterministic canonical conservative request-evaluation trace and bounded
  reducer-consumption audit are returned for all eight segment profiles.

## False in this slice

- No live provider authority or endpoint/retry behavior is certified.
- Conservative request evaluation is not an exact Graph call trace or exact
  Graph execution order. Overplanned rows may be unconsumed.
- The selected field-semantics v1 dependency binds NPM and Flash evidence, but
  this executor does not run Flash or combine Factory/Pool scheduling.
- Dynamic data-source stages and post-fatal Graph execution are not modeled.
- No output, Store, `graph_out`, EntityChanges/BlockChanges, package consumer,
  checkpoint, continuity, history, physical parity, or PoI path is added.
- Backfill and production readiness remain false.

This slice advances the repository-only observation-execution proof. It does
not satisfy a live-integration, end-to-end output, parity, or readiness
checklist item on its own.
