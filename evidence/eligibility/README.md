# Eligibility evidence

Evidence files are immutable, append-only snapshots generated by
`scripts/capture-eligibility.py`. Store them under:

```text
evidence/eligibility/<deployment>/<YYYYmmddTHHMMSSZ>.json
```

The corresponding target binding records the relative path and the SHA-256 of
the exact file bytes. Never replace an older snapshot or copy an ETA out of an
issue comment. Capture a new snapshot and update the binding in a reviewed
commit.

No evidence is committed initially because the repository does not contain a
fresh, source-complete 24-hour and 72-hour measurement for every required
cluster. Until such evidence is captured, all target gates remain
`indeterminate` and closed.
